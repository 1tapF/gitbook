# Getting started

New to the platform? These pages walk you through everything you need to know to ship something real.

## What you'll need

Before you start, make sure you have:

* [ ] An account on the platform (free plans work fine)
* [ ] A repository or local project you'd like to deploy
* [ ] A few minutes of uninterrupted time

{% hint style="info" %}
If you're evaluating the platform for your team rather than yourself, jump to [Core concepts](https://app.gitbook.com/s/kepFmiEIkBHxIOkthRLs/core-concepts "mention") first — it'll save time when you set things up properly.
{% endhint %}
